# 루틴 템플릿

## `_project.md`

```markdown
# {프로젝트} — 루틴 공통

> 이 레포의 모든 루틴이 먼저 읽는 프로젝트 공통 사실. 한 업무에만 해당하면 그 루틴 파일에 적는다.

## 제품
- 한 줄 정의
- 제품 사실의 출처: {팩트시트 등 경로} (이 파일에 기능·가격·버전을 복사하지 않는다)

## 경로·키 (실측값 — 유추 금지)

| 항목 | 값 |
|---|---|
| {문서·데이터 소스·대시보드} | {경로 / ID / 키체인 항목 이름} |

## 지난 결과 위치
- {루틴 산출물이 쌓이는 곳}

## 금지 (모든 업무 공통)
- 브랜드 이름으로 하는 공개 게시는 투두 승인 후에만
- {프로젝트 고유 금지사항}
```

## 루틴 파일 `<업무>.md`

```markdown
---
name: {프로젝트} · {업무}
schedule: "0 18 * * *"
run: /{스킬} {단계}
model: claude-sonnet-5
budgetUsd: 3
maxTurns: 100
approval: bypass
overlap: skip
outputs:
  todos: true
  todoOnFailure: true
  vault: projects/{프로젝트}/{업무}/{date}.md
---

## 이번 기간 목표
- {지금 집중할 것. 기한이 지나면 지운다}

## {단계1}
- {이 단계에서만 적용할 기본값과 다른 점}

## {단계2}
- …
```

섹션 이름(`## 단계`)은 `run`이 가리키는 스킬이 정한다. 스킬 문서를 보고 맞춘다.
